## Entities

### 1. Room

Exists only in server memory (`server/src/services/roomService.js`). Holds the ordered log of all drawing operations that represents the current canvas state.

```
Room {
  roomId:         string          // 6-char, A–Z 0–9, server-generated
  operations:     DrawingOperation[]  // ordered by sequenceNumber ascending
  nextSequence:   number          // monotonically increasing counter (starts at 1)
  connectedUsers: Set<string>     // set of userId strings currently connected
  gracePeriodTimer: TimeoutRef | null  // clearTimeout handle for TTL eviction
  createdAt:      Date
  lastActivityAt: Date            // updated on every operation and join/leave
}
```

**Lifecycle**:
1. Created on `room:create` → `roomId` generated server-side.
2. Destroyed 45 s after `connectedUsers` drops to 0 (grace period timer).
3. Grace period cancelled when a new socket joins the room before the timer fires.
4. All state is lost on server restart (acceptable for MVP).

**Validation rules**:
- `roomId` matches `/^[A-Z0-9]{6}$/`.
- `connectedUsers` may be empty (room persists during active grace period).

### 2. DrawingOperation

An immutable record of a single user action in the room. Appended to `Room.operations` after server deduplication. Replayed in `sequenceNumber` order to reconstruct canvas state for new joiners.

```
DrawingOperation {
  operationId:    string    // UUID v4 — client-generated before emit
  sequenceNumber: number    // server-assigned, unique per room, starts at 1
  type:           'DRAW' | 'ERASE' | 'CLEAR'
  userId:         string    // UUID v4 — session-scoped, server-assigned on connect
  points:         Point[]   // DRAW / ERASE only; empty array for CLEAR
  timestamp:      number    // server-assigned unix ms
}

Point {
  x: number   // virtual coordinate, 0–1920
  y: number   // virtual coordinate, 0–1080
}
```

**Field rules by type**:

| Type    | `points`   | Notes |
|---------|------------|-------|
| `DRAW`  | required, ≥ 2 | Ordered sequence of pointer positions forming the stroke |
| `ERASE` | required, ≥ 1 | Each point is the center of the eraser circle (radius = `ERASER_RADIUS` constant) |
| `CLEAR` | `[]`       | Signals a full canvas reset; all preceding operations are visually overridden |

**Idempotency**: The server checks `operationId` against a per-room Set of seen IDs before accepting an operation. Duplicate `operationId` is silently discarded.

**Convergence**: Replay algorithm for a given room:
1. Find the index of the last `CLEAR` operation (if any) in `operations` sorted by `sequenceNumber`.
2. Discard all operations at or before that index (they are visually overridden).
3. Replay remaining `DRAW` and `ERASE` operations in `sequenceNumber` order.

### 3. UserSession

Transient server-side identity assigned automatically when a socket connects. Never persisted.

```
UserSession {
  userId:     string    // UUID v4 — generated by server on socket connect
  socketId:   string    // socket.io socket.id
  roomId:     string | null  // room the user is currently in (null before join)
  connectedAt: Date
}
```

**Lifecycle**:
1. Created in `socket.on('connect')` handler.
2. `roomId` set when user emits `room:join` or `room:create`.
3. Destroyed on socket `disconnect`; `Room.connectedUsers` updated accordingly.

## State Transitions

### Room State Machine

```
            [room:create]
                  │
                  ▼
            ACTIVE ──── [socket joins] ──▶ ACTIVE (connectedUsers++)
              │   ◀─── [socket leaves] ─── ACTIVE (connectedUsers--)
              │
   [connectedUsers drops to 0]
              │
              ▼
         GRACE_PERIOD (45s timer running)
              │
    ┌─────────┴────────┐
    │                  │
[timer fires]  [socket rejoins before timer]
    │                  │
    ▼                  ▼
  EVICTED           ACTIVE
 (deleted)       (timer cancelled,
               connectedUsers++)
```

### Connection Status (Client)

```
DISCONNECTED ──[socket connects]──▶ CONNECTED
CONNECTED ──[socket disconnects]──▶ RECONNECTING
RECONNECTING ──[socket reconnects]──▶ CONNECTED
CONNECTED ──[room:error ROOM_NOT_FOUND]──▶ redirect to homepage
```

## Validation Rules

| Field | Rule |
|-------|------|
| `roomId` (client input) | Exactly 6 chars, A–Z 0–9 after uppercase normalisation; validated client-side before any server call (FR-003) |
| `operationId` | UUID v4 format; server rejects duplicates per room |
| `points[].x` | Number, 0 ≤ x ≤ 1920 |
| `points[].y` | Number, 0 ≤ y ≤ 1080 |
| `type` | One of `DRAW`, `ERASE`, `CLEAR` |
| `points` for `CLEAR` | Must be empty array `[]` |
| `points` for `DRAW` | At least 2 points |
| `points` for `ERASE` | At least 1 point |
